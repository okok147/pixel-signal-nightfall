# Nightfall audio credits

The prototype uses the following downloaded, permissively licensed resources.
The files are renamed into `Assets/Resources/Audio/Nightfall/` so Unity can
load them at runtime.

- `Nightfall_BGM.mp3` — “Going Up - adventure Chiptune” by Ansimuz. CC0; optional credit. Source: <https://opengameart.org/content/going-up-adventure-chiptune>
- `Nightfall_Ambience.mp3` — “Crickets Ambient Noise - loopable” by Ted Kerr / Wolfgang_. CC0; optional credit. Source: <https://opengameart.org/content/crickets-ambient-noise-loopable>
- `SFX_Shoot.wav`, `SFX_Hit.wav`, `SFX_BossBurst.wav`, `SFX_LevelUp.wav`, `SFX_Shard.wav`, `SFX_Select.wav`, `SFX_Result.wav` — selected sounds from “8-Bit Sound Effect Pack (Vol. 001)” by Deva / @Shades. CC0; credit appreciated. Source: <https://opengameart.org/content/8-bit-sound-effect-pack-vol-001>
- `SFX_UI_Click.wav`, `SFX_UI_Rollover.wav` — selected sounds from Kenney’s “51 UI sound effects”. CC0; credit appreciated. Source: <https://lpc.opengameart.org/content/51-ui-sound-effects-buttons-switches-and-clicks>
